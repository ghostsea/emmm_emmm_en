# 逐张手牌行动图排序：独立候选

基于已采用探测器覆盖版；保留大战略信用储备扣分。此前消融第6组显示，阿米巴牌原始分17.8211→24.8211后挤掉原始23.935782的b90，但行动图36.02低于b90原有51.75，最终改选43.222的扫描。取消储备的24组整体结果为负，不合入。

本候选把每张当前合法、可支付的手牌包装为普通打牌主行动，用与主决策相同的行动图、终局边际和风格修正计算后，选出图分最高的代表牌。原始分不改，资源不改，不读取未来牌序。图分相同依次比较原始分、原手牌顺序；图接口不可用则保留原始分回退。行动图中的嵌套分和早期打牌高于PASS的保护读取选中实例，避免借用另一张牌的分数/直接分。已有实际选牌实例约束继续使用。

此处排序发生在通用行动图阶段；后续扫描/打牌/PASS之间已有的特定局势压力仍作用于代表牌，尚未扩成所有牌与其他行动的联合优化。不能声称所有上下文限制下都取得全局最优。每张牌的原始加权分、实例和图分写入cardGraphAlternatives，完整局审计需检查图预选与实际付款；原始成本模型和历史压力并未因此自动正确。

54测试文件通过，新增用例覆盖较低原始分的较好图候选、提高另一候选分不丢失原选项、真正更高图分改选、非法牌排除、输入不变及第二次完整手牌图计算保持同分。内存恢复旧原始分预选的负对照触发预期断言。

真实浏览器从固定第6组基线重放到选择前，保存完整盘面。恢复会重建火箭标识和当前玩家的任务UI缓存；夹具显式还原两者及UI默认字段，然后逐字段比较全部状态，只排除时间戳，正式恢复代码未改。现有阿米巴储备惩罚仍7；仅在诊断候选副本中给该牌+7，原始预选会改为阿米巴，但图排序保留b90的51.75，高于阿米巴36.02。预览不改盘面。真实自动选择和执行均为同一个b90实例，支付前后信用2→0，扫描结算后信用回到2、数据0→4、分数67→74，0 bug。不能把这些单步奖励当作相对基线新增收益。
