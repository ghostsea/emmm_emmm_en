# 终局资源返还：独立候选

终局资源耗尽惩罚先扣卡牌支付，再纳入确定的即时信用/能量返还；信用或能量耗尽、合计低储备、分析和扫描支付判断共享这份余额。原卡牌收益、基础费用、替代用途和惩罚权重保持，不把返还资源重复加进收益分。所有公司采用相同规则，不按开发结果挑公司。

仅支持整条效果链均为直接非负资源、补牌、精选、补数据或skipCost明确为true的卡牌科技。存在条件、收入、移动、外星人奖励、显式cost/extraCost或非展开repeat时返回未知并维持旧判断；不预支未来收入，不声称完整模拟任意卡牌。可选后续科技奖励未预估为资源，记录的afterGuaranteedReturn是最低确定返还后的余额。
