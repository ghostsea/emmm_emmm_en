# 寰宇本卡收入：独立候选

当前固定24组中，寰宇11张带将本卡放入收入区效果的实体牌曾进入合法候选，均未打出。现模型将该效果落入通用card_默认2分；运行时会把已打出的同一张牌放入收入区，提升自身收入类型并立即兑现，无需再弃第二张牌。仅针对寰宇把这部分改为本牌即时收入资源价值，加余下轮次收入资源价值；首两轮信用/能量/手牌为6/6.2/5.4，后两轮采用现行4.5/4.2/4.3（补牌按控制器AI_RESOURCE_VALUES.handSize=4.3；此前文案写3有误，冻结源码和实测JSON始终为4.3）。不为远期沿用首轮溢价，不新增行动优先级，原信用费用及本牌替代用途成本继续计入。其他公司保留现模型。

54个Node测试通过。六个浏览器受控场景覆盖三张牌b42/b47/b79在R1/R4实际付款、立即资源、收入轨提升、本卡移出手牌且不额外弃牌；重复预览不改快照、不调用随机数。未来收入尚未在这些短场景中观察，资源价值不等于最终分数。此候选不包含正在随机验证的蓝科技循环；完整固定24组评估后再判断是否值得新随机验证。
