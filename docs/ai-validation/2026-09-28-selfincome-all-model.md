# 本卡转收入通用估值候选

从默认011/解析器27独立修改：所有公司打出具有 `TUCK_PLAYED_CARD_TO_INCOME` 效果的牌，按该物理牌真实收入图标，计算本次即时领取与后续轮初领取。沿用当前分轮资源单价，不额外扣第二张手牌；普通打牌费用和该牌机会成本仍由原调用方计入。无已知源牌或无真实收入图标保持原估值。主候选构造和 `scoreAiPlayCardValue` 已知牌回退路径均传入源牌，避免同牌两套效果价值。

此候选扩大了先前仅寰宇实验的适用范围，也修正已知牌回退路径，不能称为相同模型复测或相加历史收益。固定完整24组后，均分第一、高分第二，同时公开所有公司和低尾。仅开发正向才冻结新随机；尚无整局提分结论。

54项Node测试、语法检查通过；18个真实浏览器受控场景覆盖三家公司、R1/R4、b42/b47/b79，验证实际费用、即时资源、收入栏增加、无额外弃牌及重复估值不改状态/RNG。测试将大战略蓝奖励槽设为已占，黄/红为空；b47另核对公司黄槽+1信用，避免把该被动算成收入。未来轮初领取只按规则建模，本组未推进未来轮次，不将其称为实测收益。
