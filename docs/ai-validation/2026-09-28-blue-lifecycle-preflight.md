# 蓝色科技循环收益候选，尚未验收提分

候选从当前默认 2ecf661a 分支；只调整三家电脑公司第1至3轮的蓝1/蓝2收益模型。资源循环先验来自当前默认完整24局：寰宇66次分析/24席/4轮=0.6875，作弊232/48/4=1.2083333333，大战略95/24/4=0.9895833333。不能把历史版本的蓝科技提分作为本版证据。

将两轮先验与本局已完成轮次的实际分析次数混合。两轮权重是待验证参数，不是规则或实测因果关系。当前奖励按实际槽位前置数据缺口折算；第一排已经放过数据时不补算2分。未来轮次按该轮资源价值计算，每次蓝色附加奖励扣1数据，计算机列分另计。未来资源价值不沿用首轮溢价；分析能量门槛只是必要条件，未来补数据与能量充足并未得到保证，故循环频率是统计预测。

有正值预测时替换旧的通用蓝色引擎/路线项及两项早期公司蓝色奖励项，保留科技实际即时奖励、成本和终局公式。预测为0、末轮、蓝3/蓝4、非这三家公司均沿用原评分。没有增加资源、改放置规则或强制行动顺序。

验证：控制器语法检查、全部54个Node测试通过。真实浏览器连续两次构造候选完全一致，恢复快照相同且Math.random调用0；实际科技购买与蓝色附加格奖励执行成功，1数据换1资源，0运行错误。浏览器夹具限制了科技集合并强制后续放数据，只证明执行链，不能证明自主选择收益。候选详细分解、被替代科技及最终资源转换必须由完整24组开发对照继续核查。通过后再冻结新随机种子；不与异常点/精选/标记移除候选叠加，不以少数高分局验收。
