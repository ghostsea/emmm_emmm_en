# 将电脑轮次补助与其他获取分开

本次从当前固定24局的逐步骤记录中，单独提取第2–4轮明确发放的电脑补助。96席补助数量逐公司一致。只拆分日志中明确的轮次发放，不将开局收入优势、费用折扣、免费发射或免费行动折算成资源。

|---|---:|---:|---:|---:|---:|
|寰宇超动力|1|4|3|4|2.083 / 6.417 / 8.417|
|宇宙大战略集团|1|1|0|4|7.417 / 6.917 / 15.833|
|作弊实验室|1|4|0|4|3.542 / 8.500 / 12.771|

真人寰宇3份日志的非收入获取均值为6.667信用、13.667能量、16.667手牌。与扣除明确轮次补助后的AI寰宇相比，分别多4.583、7.250、8.250。真人还取得更多信用收入（20.667对15.833）和更多完整数据循环（5对1.625）。这支持继续追踪玩家如何通过打牌、星球奖励、外星人和蓝色科技补给，而不能把AI的免费补助计作策略自己产生的收益。

这些不是匹配对局：真人日志版本、公司规则、外星人和种子不同，旧日志存在缺项；无法从上述差值直接预测提分。快照推断但来源不明的获取保留在“其他非收入”，没有强行归给补助或具体能力。各席原始步骤及数量在配套JSON中。
